## Quick Started
You need to install `@sugarat/cli` first
```sh
npm i -g @sugarat/cli
```

then you will get `q` and `sug` command

install cli plugin

```sh
sug install hello [words...]
sug install hello
sug install hello 真不戳

# equal
sug install @sugarat/cli-plugin-hello@latest
```

then you `sug` have hello command
```sh
sug hello
```
