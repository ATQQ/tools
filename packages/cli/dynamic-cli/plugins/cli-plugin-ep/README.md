## Quick Started
You need to install `@sugarat/cli` first
```sh
npm i -g @sugarat/cli
```

then you will get `q` and `sug` command

install cli plugin

```sh
sug install ep

# equal
sug install @sugarat/cli-plugin-ep@latest
```

then you `sug` have ep command
```sh
sug ep
```
