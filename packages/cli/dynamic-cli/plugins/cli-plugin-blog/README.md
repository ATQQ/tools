# @sugarat/cli-plugin-blog

用于博客内容分发其它平台的格式转换

![](https://img.cdn.sugarat.top/mdImg/MTY3NjEyNzk1ODIyOA==676127958228)

## Quick Started
You need to install `@sugarat/cli` first
```sh
npm i -g @sugarat/cli
```

then you will get `q` and `sug` command

install cli plugin

```sh
sug add blog

# equal
sug install @sugarat/cli-plugin-blog@latest
```

then you `sug` have blog command
```sh
sug blog
```
